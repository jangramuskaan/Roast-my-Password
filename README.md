# 🔥 Roast My Password

A cybersecurity-themed web application that analyzes password strength, detects weak patterns, estimates crack time, and humorously roasts insecure passwords.

---

## 📖 About The Project

Weak passwords remain one of the leading causes of security breaches worldwide.

Roast My Password helps users understand the strength of their passwords through interactive security analysis and entertaining feedback.

Instead of simply showing a score, the application:
- Evaluates password strength
- Calculates security metrics
- Estimates crack time
- Detects common breached passwords
- Provides humorous cybersecurity-themed roasts

---

## ✨ Features

### 🔐 Password Strength Analysis
- Real-time strength scoring
- Visual strength meter
- Color-coded security levels

### ✅ Password Checklist
Checks for:
- Minimum length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

### 🚨 Breach Detection
Warns users if their password matches commonly compromised passwords.

### 📊 Security Dashboard
Displays:
- Security Score
- Crack Time Estimate
- Password Entropy

### 😂 Password Roasting
Provides funny and engaging feedback based on password strength.

### 💻 Hacker Terminal Simulation
Simulates a basic password attack scenario:
- ACCESS GRANTED
- ACCESS DENIED

### 🔑 Password Generator
Creates strong random passwords instantly.

### 📋 Copy Password
One-click password copying functionality.

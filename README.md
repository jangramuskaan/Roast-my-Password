# 🔥 Roast My Password

A fun cybersecurity-themed React application that analyzes password strength and roasts weak passwords with humorous feedback.

## Features

- Password Strength Meter
- Funny Roast Generator
- Password Visibility Toggle
- Secure Password Generator
- Crack Time Estimator
- Copy Password Button

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS3
